# All Things AI Fan Site

A personal, independent fan site about why I love All Things AI: meeting cool people and connecting with tech-curious people in the Research Triangle Park area.

## Run locally
Open `index.html` in any modern browser. No installation or build step is required.

## Deploy
Import this GitHub repository into Vercel as a static site, with no build command, or enable GitHub Pages from the root of the main branch.

## Notes
This is an unofficial fan site. The skyline and decorative art are CSS, not photographs. Built with HTML, CSS, and JavaScript.
